# 知识库首页

这里是可迭代知识库的起点。

## 工作方式

- Markdown 文件是知识库真实内容源。
- MySQL 负责账号、角色、权限、文章索引、AI 会话和 MCP 配置。
- AI 只生成草稿，用户确认后才会写入 Markdown。
- 删除、覆盖和 AI 写入都会要求二次确认。

## 第一批权限

- `kb:view`
- `kb:create`
- `kb:update`
- `kb:delete`
- `ai:use`
- `ai:write_kb`
- `mcp:configure`
- `user:create`
- `user:update`
- `user:disable`
- `user:delete`
- `role:assign`
