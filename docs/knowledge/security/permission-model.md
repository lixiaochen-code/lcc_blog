# 权限模型设计

## 目标

权限模型用于控制不同用户能查看、编辑、删除或管理哪些资源。知识库系统中，权限边界尤其重要，因为 AI 可以辅助生成内容，但不能绕过用户授权直接写入。

## 基础概念

- 用户：系统中的登录主体。
- 角色：一组权限的集合，例如超管、编辑、只读。
- 权限：具体能力，例如查看文章、更新文章、使用 AI。
- 审计日志：记录关键操作的执行者、时间和目标。

## 当前权限示例

- `kb:view`：查看知识库。
- `kb:create`：创建文章。
- `kb:update`：更新文章。
- `kb:delete`：删除文章。
- `ai:use`：使用 AI 助手。
- `ai:write_kb`：确认写入 AI 草稿。

## 安全原则

AI 只生成建议和草稿。真正的写入、删除和权限变更必须由后端验证用户权限，并在用户确认后执行。
