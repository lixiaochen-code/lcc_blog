# 发布检查清单

## 发布前

- 确认代码已合并到目标分支。
- 确认依赖锁文件与安装结果一致。
- 执行类型检查、代码检查和构建。
- 检查环境变量是否配置完整。
- 确认数据库迁移脚本已经评审。

## 发布中

- 按顺序部署后端、前端和静态资源。
- 观察服务启动日志。
- 验证健康检查接口。
- 执行核心用户路径冒烟测试。

## 发布后

- 观察错误日志和性能指标。
- 检查关键接口响应时间。
- 记录版本号和发布时间。
- 准备回滚方案。

## 知识库项目建议

本地开发阶段可以先使用 JSON 存储。接入 MySQL 后，发布前需要特别检查数据迁移、权限初始化和文件路径兼容性。
