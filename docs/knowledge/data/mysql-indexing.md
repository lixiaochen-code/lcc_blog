# MySQL 索引设计入门

## 索引价值

索引可以减少数据库扫描的数据量，提高查询性能。它适合用于高频查询条件、排序字段和关联字段。

## 常见索引

- 主键索引：保证记录唯一，通常用于 `id`。
- 唯一索引：保证业务字段唯一，例如用户名、文章路径。
- 普通索引：加速常见查询条件。
- 联合索引：适合多个字段组合查询。

## 设计原则

- 优先覆盖真实查询，不为不存在的查询提前建索引。
- 区分高选择性和低选择性字段。
- 注意联合索引的最左匹配规则。
- 写入频繁的表不要过度添加索引。

## 知识库场景

文章表可以为 `path` 建唯一索引。会话消息表可以为 `conversation_id` 建索引，方便按会话加载消息列表。
